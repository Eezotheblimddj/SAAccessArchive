# SA Access Archive

An accessible archive client for blind and visually impaired users in South Africa.

Developed by Raeez Kuhn, also known as Eezo the Blind DJ.

Version 1.1

---

## What is SA Access Archive?

SA Access Archive is a Windows application for browsing and downloading files from an accessible archive over the internet, as well as browsing folders on your own computer.

It is designed from the ground up for blind and visually impaired users. Every part of the interface works with screen readers such as NVDA, JAWS, and Narrator. It is fully keyboard driven, with audio cues to confirm actions.

The project is South African, made by a blind South African developer, and aimed at the South African blind community.

---

## What you can do with it

- Browse folders on your own computer, with full screen reader support
- Connect to a remote archive over the internet using WebDAV
- Browse the remote archive the same way you browse your own folders
- Download files from the remote archive to your computer
- Search the current folder by typing part of a name
- Jump to items by pressing a letter or number
- View detailed information about any file, including size, dates, and path
- Save your preferences so the app remembers them next time

---

## Who it is for

Blind and visually impaired users who want an accessible way to browse and download files, and access an archive of games, addons, apps, screen readers, tutorials, and other accessible resources from South Africa and beyond.

The app is also useful for any user who prefers a fast, keyboard-driven file browser.

---

## Requirements

- Windows 10 or Windows 11 (64-bit)
- A screen reader (NVDA, JAWS, or Narrator) if you are a blind user
- An internet connection for connecting to remote archives
- No installation of Python or any other tool is required. The application is fully standalone.

---

## Installation

1. Download the SAAccessArchive folder to your computer.
2. Extract it if it arrived as a zip file.
3. Open the folder and find SAAccessArchive.exe.
4. Press Enter or double-click to run it.
5. If Windows shows a security warning, choose "More info" and then "Run anyway." This is normal for any application that is not yet signed with a commercial certificate.

There is no installer. The application runs directly from the folder.

---

## First-time setup

When you first run the app, it opens in your Documents folder by default. To use the remote archive feature:

1. Press Alt+S to open the Settings menu.
2. Choose Server Settings.
3. Enter the server address, username, and password for the archive you want to connect to.
4. Choose Save.
5. Press Alt+S again, and choose Connect to Server.

The archive you connect to will then appear in the list, and you can browse it like any folder on your computer.

To change where downloaded files are saved, press Alt+S and choose Set Download Folder.

To change which folder opens on startup, press Alt+S and choose Set Local Start Folder.

## Keyboard shortcuts

### Moving around

- Up and Down arrows: move through the list
- Home: jump to the first item
- End: jump to the last item
- A letter or number: jump to the next item starting with that letter or number
- Enter: open a folder, or download a remote file
- Backspace: go up one level
- Escape: clear a search, or close the application
- F5: refresh the current folder

### Working with items

- I: show detailed information about the selected item
- Ctrl+F: search the current folder by name
- Ctrl+D: download the selected remote file

### Application

- Ctrl+Q: quit
- F1: show the list of keyboard shortcuts

### Menus

- Alt+F: File menu
- Alt+N: Navigate menu
- Alt+S: Settings menu
- Alt+H: Help menu
- Alt+A: About menu

---

## Audio cues

The app plays short tones to confirm actions:

- A high tone when the app starts
- A soft click when a folder opens
- A rising tone when a download finishes
- A low tone when something fails

Sounds can be turned off at any time from the Settings menu. Choose Toggle Sounds.
